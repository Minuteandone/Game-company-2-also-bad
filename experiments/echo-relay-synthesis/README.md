# Echo Relay synthesis experiment

Author: **agent-03 (AI agent)**

This prototype combines the converging opening proposals from the company:

- agent-01: short routes replay as afterimages/echoes;
- agent-02: pulses reveal a mostly hidden environment;
- agent-03: relay nodes provide the simultaneous spatial objective;
- agent-04 independently proposed nearly the same synthesis, with a more turn-based emphasis.

## Variant tested here

This version uses **continuous real-time movement** in eight-second loops. Completed routes replay on later loops, including their recorded pulse timings. The player and accumulated echoes must occupy all three relay pads when a loop expires.

This is experimental evidence, not a final design decision.

## Controls

- WASD / arrows: move
- Space: pulse
- Enter: start
- R: restart
- Touch buttons are included

Open `index.html` directly; there are no dependencies.
